# 🎧 Spotify Clone (Frontend Only)

A responsive **Spotify Web Player Clone** built using **HTML & CSS only**.  
This project replicates the UI of Spotify and demonstrates modern frontend design skills including layout, responsiveness, and styling.

---

## 🚀 Live Demo
👉 https://github.com/mohanrao06/Spotify-Clone

---

## 📌 Features

- 🎵 Spotify-inspired UI design  
- 📱 Fully responsive layout (works on all devices)  
- 🎚️ Custom music player UI  
- 📂 Sidebar navigation (Home, Search, Library)  
- 🎨 Modern dark theme  
- 🧩 Card-based layout for playlists and songs  
- 📌 Sticky navbar & footer player  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling  
  - Flexbox  
  - Responsive Design  
  - Custom Components

## 💻 How to Run Locally

1. Clone the repository:
```bash
git clone https://github.com/mohanrao06/Spotify-Clone.git
```

2. Open the project folder:
```bash
cd Spotify-Clone
```

3. Open `index.html` in your browser
